# 阴影贴图的遗留问题与滤波化软阴影

  
‍

---

  
‍

## 1 阴影贴图基础与遗留问题

  
‍

### 1.1 问题

  
‍

阴影贴图（shadow map，Williams, 1978 [1]）思路：从光源渲染最近表面深度得到 $z(\mathbf{p})$；渲染相机视图时，将着色点变换到光空间，得到阴影贴图坐标 $\mathbf{p}$ 与到光源的深度 $d(\mathbf{x})$，执行阴影测试：

  
‍

$$

s(\mathbf{x}) = \begin{cases} 1 & d(\mathbf{x}) \le z(\mathbf{p}) + b \\ 0 & \text{otherwise} \end{cases}

$$

  
‍

其中 $b$ 为偏移量，$s=1$ 表示受光。离散化带来三类问题：

  
‍

- **透视走样/锯齿**：近处多个像素映射到同一纹素（texel），呈现锯齿 [12]。（主要因透视出现分辨率不一致）

- **阴影痤疮**：深度在整个纹素上量化，着色点深度与纹素深度极为接近，测试结果随机在受光与遮挡之间变化 [12]。

- **Peter Panning**：消除痤疮所加的偏移过大，阴影与物体脱离 [12]。

  
‍

‍

‍

![阴影痤疮](<https://img.thirra.com/pcss-share/ms-shadow-acne.jpg>)

*图 1-2 阴影痤疮（左）与消除后的结果（右）。来源：Microsoft Learn，Common Techniques to Improve Shadow Depth Maps，Figure 8。*

  
‍

![Peter Panning](<https://img.thirra.com/pcss-share/ms-peter-panning.jpg>)

  
‍

*图 1-3 Peter Panning（左，圆圈标出阴影与物体脱离）与正确结果（右）。来源：Microsoft Learn，Common Techniques to Improve Shadow Depth Maps，Figure 9。*

  
‍

### 1.2 方法

  
‍

- **偏移**：常量偏移 $d' = d - b_0$；斜率缩放偏移 $b = b_0 + b_1\max(|\partial z/\partial x|,|\partial z/\partial y|)$，表面越倾斜偏移越大；法线偏移，沿法线位移着色点后再查询。

- **紧致的光空间视锥与近远平面**，缩小渲染阴影贴图的体积，进而增大纹素密度，减少痤疮与 Peter Panning [12]。

- **级联阴影贴图**（CSM）：沿 $z$ 轴将视锥划分为若干子视锥，各分配一张阴影贴图，近处采样密度更高，用于缓解透视走样 [11][12]。

  
‍

### 1.3 遗留问题

  
‍

- 偏移需针对场景调节，不存在保证无伪影的取值：偏移过大造成漏光，过小造成自遮挡 [11]。

- 阴影边缘仍是二值的硬边，放大时呈现锯齿，需要对边缘滤波。

## 2 PCF：对阴影测试结果滤波

  
‍

### 2.1 问题

  
‍

纹理可以先滤波后采样，阴影贴图不行：深度被平均后，阴影测试仍为二值结果，硬边只是被错误地移动。阴影测试是非线性的，测试与滤波的顺序不能交换 [11][12]。

  
‍

### 2.2 方法

  
‍

Percentage-Closer Filtering（PCF，百分比渐变滤波）（Reeves 等，1987 [2]）先测试后滤波：对核内每个样本读取深度并测试，再对测试结果加权平均：

  
‍

$$

V(\mathbf{x}) = \sum_{i=1}^{N} w_i\, \mathbb{1}\left[\, d(\mathbf{x}) \le z(\mathbf{p}+\boldsymbol{\delta}_i) + b \,\right], \qquad \sum_i w_i = 1

$$

  
‍

$V\in[0,1]$ 为受光比例。

  
‍

![PCF 示意](<https://img.thirra.com/pcss-share/nv-pcf-4tap.png>)

  
‍

*图 2-1 4 样本 PCF：4 次深度测试取平均，得到 {0, 0.25, 0.5, 0.75, 1.0} 之一。来源：NVIDIA，Percentage-Closer Soft Shadows（SIGGRAPH 2005 演示文稿）[**4**]，第 8 页。*

  
‍

### 2.3 遗留问题

  
‍

**（1）开销随核增大而增长。** 核内所有样本均须求值，无法使用 mipmap 等预计算（理由同为何不能先滤波后采样）；最坏情况需要比较整张阴影贴图 [6][11]。

  
‍

**（2）大核的偏移问题。** 阴影测试只对该像素映射到的纹素有效。核增大后，邻近纹素的深度与当前着色点的光空间深度不对应，部分测试错误失败 [12]。

  
‍

![大核 PCF 的错误自遮挡](<https://img.thirra.com/pcss-share/ms-pcf-self-shadow.png>)

  
‍

*图 2-2 大核 PCF 的错误自遮挡：着色点的光空间深度与相邻纹素（1、2、3）比较，其中一个测试错误失败。来源：Microsoft Learn，Cascaded Shadow Maps，Figure 11。*

  
‍

**（3）模糊不等于软阴影。** 固定大小的核得到均匀宽度的模糊边缘；面积光源的半影宽度随遮挡物与接收面的距离变化，接触处应当变硬 [11]。

  
‍

![PCF 对软阴影的错误](<https://img.thirra.com/pcss-share/gdc-pcf-wrong.png>)

  
‍

*图 2-3 PCF 用于软阴影时的错误：左，PCF 给出 Shadow(P) > 0，参考值为 0；右，PCF 给出 Shadow(P) < 1，参考值为 1。来源：Bavoil，Advanced Soft Shadow Mapping Techniques（GDC 2008）[**5**]，第 55 页。*

## 3 PCSS：随遮挡距离变化的半影

  
‍

### 3.1 问题

  
‍

滤波核需要随遮挡物与接收面的距离自适应变化。下图对比常规阴影贴图（始终为硬边）、均匀软阴影（始终为软边）与接触硬化的软阴影。

  
‍

![常规阴影贴图、均匀软阴影与 PCSS](<https://img.thirra.com/pcss-share/nv-pcss-compare.png>)

  
‍

*图 3-1 左：常规阴影贴图；中：均匀软阴影；右：PCSS（阴影在接触处变硬）。来源：NVIDIA，Percentage-Closer Soft Shadows（SIGGRAPH 2005 演示文稿）[**4**]，第 4 页。*

  
‍

### 3.2 方法

  
‍

Percentage-Closer Soft Shadows（Fernando, NVIDIA, 2005 [3]）在每个像素处执行三步：

  
‍

1. **遮挡物搜索**：在阴影贴图的搜索区域内，对比接收点更靠近光源的深度求平均；

2. **半影估计**：在遮挡物、接收面、光源平行的假设下，由相似三角形估计半影宽度；

3. **可变核 PCF**：核大小与半影宽度成正比。

  
‍

设光源尺寸为 $w_{\text{light}}$（阴影贴图 UV 单位），近平面距离 $z_{\text{near}}$，接收点深度 $d_r$。

  
‍

搜索半径 [5]（工程也可以取固定值，取小了会漏掉遮挡物，取大了会增加开销）：

  
‍

$$

r_{\text{search}} = w_{\text{light}} \cdot \frac{d_r - z_{\text{near}}}{d_r}

$$

  
‍

遮挡物平均深度（若 $N_b=0$，该像素完全受光，无需滤波；取最小值会在不同遮挡物之间切换时产生伪影，因此取平均 [4]）：

  
‍

$$

\bar{z}_{\text{blocker}} = \frac{1}{N_b}\sum_{i:\; z_i < d_r - b} z_i

$$

  
‍

半影宽度 [3]：

  
‍

$$

w_{\text{penumbra}} = \frac{(d_{\text{receiver}} - d_{\text{blocker}})\cdot w_{\text{light}}}{d_{\text{blocker}}}

$$

  
‍

![半影估计](<https://img.thirra.com/pcss-share/nv-pcss-penumbra.png>)

  
‍

*图 3-2 半影宽度估计的几何关系，假设遮挡物、接收面与光源平行。来源：Fernando，Percentage-Closer Soft Shadows 白皮书 [**3**]，补充材料第 3 页。*

  
‍

滤波半径（投影到近平面，$r_{\min}$ 为抗锯齿所需的最小半径 [5]）：

  
‍

$$

r_{\text{filter}} = \max\left( \frac{d_r - \bar{z}_{\text{blocker}}}{\bar{z}_{\text{blocker}}}\, w_{\text{light}}\frac{z_{\text{near}}}{d_r},\; r_{\min} \right)

$$

  
‍

```hlsl

float PCSS(Texture2D<float> shadowMap, SamplerState pointSmp, SamplerComparisonState cmpSmp,

           float2 uv, float zReceiver, float lightSizeUV, float zNear, float minRadius)

{

    // 1. 遮挡物搜索

    float searchRadius = lightSizeUV \* (zReceiver - zNear) / zReceiver;

    float sum = 0.0; int count = 0;

    for (int i = 0; i < NUM\_SEARCH; ++i) {

        float z = shadowMap.SampleLevel(pointSmp, uv + SearchOffset[i] \* searchRadius, 0);

        if (z < zReceiver) { sum += z; ++count; }

    }

    if (count == 0) return 1.0;                       // 完全受光

  
‍

    // 2. 半影估计

    float zBlocker = sum / count;

    float radius = max((zReceiver - zBlocker) / zBlocker  *lightSizeUV*  zNear / zReceiver, minRadius);

  
‍

    // 3. 可变核 PCF

    float lit = 0.0;

    for (int j = 0; j < NUM\_PCF; ++j)

        lit += shadowMap.SampleCmpLevelZero(cmpSmp, uv + PcfOffset[j] \* radius, zReceiver);

    return lit / NUM\_PCF;

}

```

  
‍

![PCSS 步骤示意](<https://img.thirra.com/pcss-share/chalmers-pcss-steps.png>)

  
‍

*图 3-3 PCSS 三步：(a) 遮挡物搜索；(b) 以平均深度处的单一平面遮挡物估计半影宽度；(c) 按相应窗口大小滤波。来源：Eisemann 等，Efficient Real-Time Shadows（SIGGRAPH 2012 课程笔记）[**11**]，Figure 5.1。*

  
‍

PCSS 仅使用一张阴影贴图，无需预处理或额外几何，可直接替换传统阴影贴图查询。640×480、遮挡物搜索 36 个样本、PCF 64 个样本时约 75 fps（GeForce 7800 GTX）[3]。

  
‍

### 3.3 遗留问题

  
‍

1. **逐像素采样开销高。** 遮挡物搜索与滤波均为蛮力采样；半影较大时需要大量样本才能避免带状伪影（伪影不呈连续状） [9]。每个遮挡物搜索样本的开销约比 PCF 样本高 30% [4]。

2. **噪声与带状伪影。** 样本不足出现带状伪影，加入抖动则转为噪声 [5]。

3. **单一平面遮挡物假设。** 核内遮挡物被压平为同一深度，光源增大时本影被低估；仅用光源中心的单张阴影贴图，深度范围大的遮挡物会出现单轮廓伪影 [9]。

4. **PCF 的偏移问题被继承。** 滤波步骤仍是 PCF [6]。

## 4 PCSS 的实用化：采样与噪声

  
‍

### 4.1 问题

  
‍

遮挡物搜索与 PCF 的样本数决定质量与开销。

  
‍

### 4.2 方法

  
‍

- **减少遮挡物搜索样本**：4×4 或 5×5 已足够，样本越多噪声越少 [5]。

- **遮罩本影与全受光区域**：先估计半影区域，仅在半影处执行 PCF [4]；遮挡物搜索得到的阴影强度大于 $1-\varepsilon_u$（$\varepsilon_u=0.01$）时直接判定为本影 [10]。

- **采样分布与逐像素旋转**：Vogel 圆盘样本位置（$N$ 为样本数，$\phi$ 为逐像素旋转角）：

  
‍

$$

r_i = \sqrt{\frac{i + 0.5}{N}}, \qquad \theta_i = i\cdot 2.39996 + \phi

$$

  
‍

交错梯度噪声（Interleaved Gradient Noise，Jimenez, 2014 [13]）生成 $\phi$，使噪声在相邻像素间交错分布，利于时域累积：

  
‍

$$

\text{IGN}(x,y) = \text{frac}\left(52.9829189\cdot\text{frac}\left(0.06711056\,x + 0.00583715\,y\right)\right)

$$

  
‍

- **替换滤波后端**：第三步可用 SAVSM、MIPCSM 等预滤波方法替代 PCF，仅需第一步确定滤波核大小 [5]。

  
‍

![遮挡物搜索采样数](<https://img.thirra.com/pcss-share/gdc-blocker-taps.png>)

  
‍

*图 4-1 遮挡物搜索 3×3 样本（左）与 5×5 样本（右）。来源：Bavoil，Advanced Soft Shadow Mapping Techniques（GDC 2008）[**5**]，第 43 页。*

  
‍

### 4.3 遗留问题

  
‍

- 噪声与带状伪影只能权衡。

- PCF 核增大时开销随核面积增长，开销仍是逐像素的。

- 需要常数时间的任意大小滤波，即预滤波阴影贴图。

## 5 可预滤波阴影贴图

  
‍

### 5.1 问题

  
‍

阴影测试是着色点深度与贴图深度的比较，结果只有 0 或 1，属于非线性运算；着色点深度在运行时才确定，比较无法提前进行。因此 mipmap、SAT、可分离模糊等线性滤波手段都不能直接用于阴影贴图 [7][11]。

  
‍

### 5.2 方法

  
‍

Peters 与 Klein（2015 [8]）给出统一描述：阴影贴图不直接存深度，而存深度的某种变换；这些量可以按普通纹理做线性滤波，滤波结果概括了核内深度的分布，再由该概括与着色点深度估计“核内有多大比例的纹素比着色点更近”，即受光比例。PCF 逐纹素比较得到的就是这个比例，预滤波方法则用近似代替逐纹素比较。各方法的差异在于存储的内容与估计方式，VSM 与 MSM 给出的是受光比例的上界，即阴影不会被过度估计，误差只会表现为偏亮（漏光）。

  
‍

**VSM**（Donnelly & Lauritzen, 2006 [14]）：存储深度与深度平方。滤波后得到核内的平均深度与深度的离散程度（方差）。着色点深度大于平均深度时，偏离越大、离散越小，着色点越可能处于遮挡之后；Chebyshev 不等式据此给出受光比例的上界。着色点不深于平均深度时，受光比例取 1。VSM 可直接使用硬件的三线性、各向异性滤波与可分离模糊 [12]。

  
‍

**ESM**（Annen 等，2008 [7]）：假设着色点不比贴图深度更近，用单项指数曲线近似“比较”的阶跃。指数可拆成只含着色点深度与只含贴图深度的两个因子：

  
‍

$$

e^{-c(d-z)} = e^{-cd}\cdot e^{cz}

$$

  
‍

阴影贴图存储 $e^{cz}$，对其滤波后乘以着色点处的 $e^{-cd}$ 即可。$c$ 越大，指数曲线越接近阶跃；32 位浮点下经验值为 $c=80$，更大的 $c$ 会使指数溢出。

  
‍

**MSM**（Peters & Klein, 2015 [8]）：存储深度的一至四次幂。存储的矩越多，对核内深度分布的描述越完整，据此得到的受光比例上界越紧。四个矩的方案在与这些矩一致的所有分布中给出最紧的上界；每纹素 64 位（四通道 16 位）。两、三通道方案明显较差。

  
‍

其余路线：LVSM 将深度区间分层，各层使用独立的 VSM [15]；卷积阴影贴图（Convolution Shadow Maps）将阶跃函数展开为约 16 项 Fourier 级数，内存与滤波开销高 [7]。

  
‍

### 5.3 遗留问题

  
‍

**漏光。** 核内存在多层相互重叠的遮挡物时，深度分布中出现一段虚假的“间隙”：平均深度与离散程度无法区分“一层遮挡物”与“多层遮挡物”，应处于阴影中的最下层表面因此得到非零的受光比例 [12]。完全被遮挡的表面上，这种错误半影的强度不会达到满值，因此可将低于某一阈值的受光比例直接视为 0，其余部分线性拉伸回 0 到 1 的范围 [6]。代价是真实的浅半影被一并压暗，细节损失。

  
‍

![VSM 漏光](<https://img.thirra.com/pcss-share/ms-vsm-light-bleeding.png>)

  
‍

*图 5-4 VSM 漏光（左，圆圈标出）与正确结果（右）。来源：Microsoft Learn，Cascaded Shadow Maps，Figure 16。*

  
‍

![漏光成因](<https://img.thirra.com/pcss-share/gg-bleeding-diagram.jpg>)

  
‍

*图 5-5 漏光成因：滤波区域内存在多层遮挡，最下层表面产生错误的半影。来源：Lauritzen，Summed-Area Variance Shadow Maps，GPU Gems 3 第 8 章 [**6**]，Figure 8-7。*

  
‍

其余遗留问题：

  
‍

- ESM 假设着色点不比贴图深度更近；核内出现比着色点更深的贴图深度（倾斜表面、深度不连续）时指数溢出，需回退到 PCF [7]。

- VSM、ESM 的估计是“单边”的：核内平均深度不小于着色点深度时没有定义，被假定为完全受光；核较大时部分被遮挡的点因此被错误判为受光（“非平面”问题）[9]。

- 软阴影需要逐像素可变的大核，并且遮挡物搜索仍是蛮力采样。

## 6 软阴影的滤波化

  
‍

### 6.1 问题

  
‍

PCSS 的遮挡物搜索与滤波均为蛮力点采样 [9]，每个像素的开销随两个区域的面积增长。第 5 章的预滤波只解决了其中一半：核的大小确定后，滤波可以预先完成；而 PCSS 的核大小由遮挡物平均深度决定，该深度本身仍需在搜索区域内采样求得。该平均值只统计比着色点更近的纹素，随着色点深度变化，同样无法直接预滤波。

  
‍

因此需要同时解决三件事：

  
‍

1. 任意大小滤波核的常数时间滤波；

2. 不经逐点采样的遮挡物平均深度估计；

3. 估计所依赖的统计假设失效时（“非平面”核）造成的错误受光。

  
‍

下文依次对应：SAT 解决第 1 项，VSSM 与 MSM 软阴影解决第 2 项，VSSM 的核细分处理第 3 项。

  
‍

### 6.2 方法

  
‍

**SAT**（Summed-Area Table，求和面积表）：二维的前缀和。一维数组 $[3, 1, 4, 1, 5]$ 的前缀和为 $[3, 4, 8, 9, 14]$，第 2 到第 4 项之和等于 $9-3=6$，只需两次读取；SAT 将此推广到二维：每个纹素存储从左上角到该纹素的矩形内所有值的累计和，任意矩形内的总和只需读取矩形四个角的值，做一次加减即可得到 [6]，除以矩形面积即为核内平均值。查询次数固定为 4 次，与核的大小无关，因此可在每个像素使用不同大小的核。SAT 滤波的是盒形核，且与第 5 章的方法配合使用：贴图中存储的是矩等可线性滤波的量，对其建立 SAT，即可对任意矩形区域取平均。SAT 的累计值很大，单精度浮点的精度不足；Peters（2016 [10]）改用 32 位无符号整数，先将矩缩放到整数范围，使核内求和落在整数可表示的范围内，并利用整数的溢出回绕，使溢出不影响差值。最大核覆盖 256 个纹素时，精度约 24 位，与单精度浮点相当。

  
‍

**VSSM**（Yang 等，2010 [9]）：目的是不经逐点采样，直接估计核内的平均遮挡物深度。核内样本分为两类：深度不小于着色点深度的（未被遮挡的表面）与更近的（遮挡物）。全体样本的平均深度已知时，若再知道两类样本各占多少、未遮挡样本的深度，就能反推遮挡物的平均深度。思路如下：

  
‍

1. 由 SAT 一次查询得到核内全部样本的平均深度；

2. 用 Chebyshev 不等式估计其中未被遮挡的样本所占比例；

3. 未被遮挡样本的深度近似取为着色点深度；

4. 全体平均值由两类样本的加权平均构成，已知平均值、未遮挡部分的比例与深度，即可反推遮挡物的平均深度。

  
‍

数值示例：着色点深度为 10，核内平均深度为 7，估得未遮挡比例为 0.5。全体平均 7 等于 0.5 × 10（未遮挡部分）加 0.5 × 遮挡物平均深度，故遮挡物平均深度为 4。整个过程不需要逐点读取阴影贴图。

  
‍

第 3 步的近似要求未被遮挡的样本与着色点大致同深，即核内是一个近似平行于光源的接收面。核内存在明显比着色点更深的表面时（例如着色点位于凸起之上，周围是较低的地面），这些样本把平均深度抬高到不小于着色点深度，上述推断失效，称为“非平面”核；此时估得的受光比例不可靠，会被当作完全受光。处理方式是将核划分为若干子核：平均深度小于着色点深度的子核按上述方式处理，其余子核改用 2×2 PCF。此外，借助 min-max 层次化阴影贴图（HSM，逐层记录区域内的最小与最大深度），可提前判定本影与完全受光的点，跳过上述计算。

  
‍

**MSM 软阴影**（Peters, 2016 [10]）：对四矩阴影贴图生成 SAT，遮挡物搜索与滤波各用一次 SAT 查询完成。遮挡物搜索时，由查询得到的四个矩重建核内深度的分布（以三个深度值及其权重表示），其中比着色点更近的部分按权重取平均，即得平均遮挡物深度。公式中另加一个很小的常数项：核内几乎没有遮挡物（阴影强度趋于零）时，权重之和趋于零，该项使结果稳定地趋向着色点深度，从而使用小滤波核，避免数值不稳定。基于 SAT 的方法可使用 27×27 的搜索区域；PCSS 在 15×15 搜索区域下耗时 8.08 ms，而 MSM 软阴影为 2.11 ms（无插值）/ 2.51 ms（插值）。

  
‍

另有卷积软阴影贴图（基于卷积阴影贴图）与指数软阴影贴图（Shen 等，2013，基于 ESM 并用较小区域的 SAT 避免精度损失），均需额外纹理用于遮挡物搜索 [10]。

  
‍

### 6.3 遗留问题

  
‍

1. **构建开销。** SAT 随阴影贴图分辨率增大成为瓶颈：VSSM 在 2048² 阴影贴图下总计 25.8 ms，其中 SAT 为 17.9 ms [9]。

2. **漏光。** 短距离阴影处仍可能出现漏光，MSM 因所需偏移小而较弱 [10]。

3. **遮挡物融合错误。** 基于 PCSS 框架的方法将不同深度的遮挡物替换为平均深度处的单一遮挡物；核内存在多于两个表面时，该错误与漏光叠加 [10]。

## 7 方法对比

  
‍

| 方法 | 阴影贴图内容 | 主要伪影 | 软阴影（可变核） |

|---|---|---|---|

| PCF | 深度 | 大核偏移；均匀模糊 | 否 |

| PCSS | 深度 | 噪声、带状；单平面假设 | 是（逐像素采样开销高） |

| VSM | $z, z^2$ | 漏光 | 需配合 SAT |

| ESM | $e^{cz}$ | 指数溢出，回退 PCF | 需配合 SAT |

| MSM | $z,z^2,z^3,z^4$ | 弱漏光 | 通过 SAT |

| VSSM | $z,z^2$ + SAT + 层次化阴影贴图 | “非平面”需细分；漏光 | 是（逐纹素构建开销高） |

| MSM 软阴影 | 四矩整数 SAT | 短距离漏光；遮挡物融合 | 是（逐纹素构建开销高） |

## 8 局限与后续方向

  
‍

- 上述方法均基于单张阴影贴图与单平面遮挡物近似，共享遮挡物融合错误与启发式参数依赖。

- Unreal Engine 5 的 Virtual Shadow Maps 以高分辨率虚拟阴影贴图缓解分辨率不足，配合 Shadow Map Ray Tracing 估计接触硬化的半影 [16]。

- 距离场阴影与硬件光线追踪阴影（配合降噪）直接基于场景表示估计光源可见性 [16]。
